# Gyros Hero – Backend

This is the Node.js backend for Gyros Hero that handles Square API communication, secure .env configuration, and any future custom backend logic.

## Features

- Fetch menu items securely from Square API
- Supports custom routes (future extensions possible)
- Clean architecture with `.env` for secrets
- Ready for deployment on Render or EC2

## Tech Stack

- Node.js
- Express.js
- Square SDK
- dotenv
- Axios

## Run Locally

```bash
npm install
node index.js
```
